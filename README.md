# Booking API App

Ứng dụng quản lý và tự động hóa dữ liệu booking KOC cho agency TikTok.

## Mục tiêu

- Quản lý chiến dịch booking theo từng khách hàng
- Theo dõi danh sách KOC trong từng chiến dịch
- Theo dõi trạng thái booking, trạng thái đăng video, link video
- Theo dõi GMV, số đơn hàng, livestream
- Đồng bộ dữ liệu về Lark Base hoặc Lark Sheet
- Chuẩn bị tích hợp TikTok API trong giai đoạn sau

## Các module chính

1. Campaign Management
2. KOC Management
3. Video Tracking
4. GMV & Order Tracking
5. Report Dashboard
6. Lark Sync
7. API Integration
