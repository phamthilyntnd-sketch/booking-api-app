# 09 — Dự án phần mềm TAPKOC

Phần mềm quản lý booking KOC, phát triển từ kinh nghiệm vận hành Team Booking.

| Hạng mục | Nội dung |
|---|---|
| Đối tượng | **Seller** (shop riêng) và **Agency** (nhiều khách/shop/chiến dịch, dữ liệu tách theo agency) |
| Kênh outreach 1 | Mời KOC hàng loạt qua TikTok Shop / TAP |
| Kênh outreach 2 | Import dữ liệu KOC + liên hệ qua Zalo, AI hỗ trợ trả lời |
| Giai đoạn mở rộng | AI mix video, đăng lên kênh khách hàng, chạy Ads |
| Quản lý dự án | File Excel làm việc: quản lý không chuyên IT đọc được, đủ chi tiết cho dev, điều phối nhân sự và nghiệm thu |
| Nhân sự | Có thể kiêm nhiệm vai trò; mô hình hợp tác dev không mặc định là tuyển lương cứng |

Nền tảng kỹ thuật tái sử dụng: logic sync TAP (`06`), bài học kỹ thuật (`07`), cấu trúc dữ liệu (`03`) và logic đối soát (`04`).
